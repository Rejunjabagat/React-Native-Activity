## 2. Architecture

```
App.tsx                         SafeAreaProvider → ThemeProvider → RootNavigator
src/
├─ theme/
│  ├─ colors.ts                 light + dark palettes (single design token file)
│  └─ ThemeContext.tsx          GLOBAL STATE: mode, colors, profile, actions
├─ navigation/
│  ├─ types.ts                  RootStackParamList (typed routes)
│  └─ RootNavigator.tsx         native-stack + navigation theme sync
├─ hooks/
│  └─ useResponsive.ts          window size → columns / gutter / padding / cardWidth
├─ data/
│  └─ activities.ts             typed activity catalogue (the dashboard content)
├─ components/                  stateless, reusable UI primitives
└─ screens/
   ├─ HomeScreen.tsx            dashboard: greeting, stats, responsive card grid
   ├─ ActivityScreen.tsx        activity detail + checklist progress
   └─ SettingsScreen.tsx        profile + appearance + live preview + about
```

### Global state flow

```
ThemeProvider (Context)
   ├── mode: 'light' | 'dark'      → colors palette, StatusBar style, navigation theme
   ├── profile: { name, course }   → Home greeting, Settings live preview
   ├── toggleTheme() / setMode()
   ├── updateProfile(patch)
   └── resetPreferences()
        │
        ├── HomeScreen      (reads colors + profile)
        ├── ActivityScreen  (reads colors)
        └── SettingsScreen  (reads + writes both values)
```

Because every screen consumes the same context, typing a name or flipping the
switch on Settings repaints the dashboard instantly — no prop drilling, no reload.

### Responsive strategy

`useResponsive()` derives everything from `useWindowDimensions()`:

| Window width | Columns | Horizontal padding | Gutter |
|---|---|---|---|
| `< 360 dp` (compact) | 2 | 14 | 14 |
| `360–699 dp` (phone) | 2 | 18 | 14 |
| `≥ 700 dp` (tablet / landscape) | 3 | 32 | 20 |

Card width is computed from the live width, so nothing overflows and cards
re-flow automatically on rotation or split-screen.

## 4. Demo script (for the screen recording)

1. Open the app — dashboard in **dark** mode, greeting shows the profile name.
2. Tap the ☀️/🌙 header icon → the whole app switches to **light** instantly.
3. Open **Settings** → type a new display name → the *Live preview* card updates
   character by character.
4. Go back → the Home dashboard greeting already shows the new name (global state).
5. Switch theme from the Settings `SegmentedControl` as well — dashboard unchanged
   visually across navigation, proving state lives above the screens.
6. Resize / rotate / open on a tablet profile → the grid re-flows from 2 to 3
   columns and nothing overflows.
7. Open an activity card → tick checklist items → progress bar and counter update.

Recording is saved as `demo/activity5-demo.mp4`.
